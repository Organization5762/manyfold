# manyfold 0.1.43

manyfold 0.1.43 completes the distributed startup and recovery control plane
introduced in 0.1.42 and qualifies it against the real Heart consumer.

## Features

- Adds bounded node bootstrap, secure machine-local signing and enrollment, and
  short-lived process credentials without exposing durable machine keys to
  client processes.
- Adds authenticated mesh and RPC integration across discovery, SWIM
  membership, navigation, low-rate sensor topics, and durable world/device
  state.
- Adds deterministic persistent Raft storage-failure boundaries for ENOSPC and
  partial-write recovery while keeping the production storage default
  unchanged.
- Adds a machine-readable 22-story release gate covering startup, convergence,
  identity, malformed discovery, partitions, leader loss, restart, quorum loss,
  persistence damage, credential lifecycle, bounded resources, and shutdown.

## Reliability

- Drops stale TCP connections by exact socket identity so a delayed cleanup
  cannot remove a newer reconnect.
- Closes pending authenticated handshakes during transport shutdown, preventing
  a peer that never completes TLS from holding a process open.
- Bounds qualification subprocesses, queues, threads, file descriptors, audit
  retention, and optional soak execution.

## Boundaries

- Durable delivery and Raft remain limited to explicit control-plane topics.
  Frame ticks, rendered frames, microphone-rate data, and debug taps stay
  process-local. Distributed navigation and sensor traffic uses transient
  delivery rather than durable queues or Raft.
- This release does not add worker-process or shared-memory architecture.
